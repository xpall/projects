filipino-talent.com

An open-source subdomain registry for Filipino remote workers, inspired by is-a.dev. It gives aspiring developers, freelancers, and remote workers a free yourname.filipino-talent.com address to point at a portfolio hosted on GitHub Pages, Cloudflare Pages, Netlify, or Vercel.
Built entirely on Cloudflare: an Astro site on Pages, a Worker API, a D1 database, and the Cloudflare DNS API for automated record management.

Visit filipino-talent.com

Project Overview

Introduction

     filipino-talent.com is a free, community-run subdomain registry for Filipino remote workers. It exists for the same reason is-a.dev does: a professional-looking web address should not require a domain budget. A user submits a form, receives a subdomain, and points it at whatever static host they already use. The site is only the front door — the real work happens in a Cloudflare Worker that talks to D1 and the Cloudflare DNS API to create and clean up records automatically.

Challenges

⏺ Free-Tier DNS Limits: The Cloudflare free plan caps a zone at 200 DNS records, so every claimed subdomain is a scarce resource that must be managed carefully.
⏺ Abuse and Squatting: An open subdomain registry invites impersonation, disposable requests, and collisions. Names need reserved-word and allowed-target validation.
⏺ Publisher Confidence: A subdomain should only go live once the requester actually controls the portfolio they claim — otherwise the zone becomes a spam host.
⏺ Safe Automation: Creating and deleting DNS records programmatically requires precise tagging so the automation never touches records it does not own.
⏺ Reversibility: Removing a subdomain must reliably tear down both the DNS record and the public directory entry without leaving orphans behind.

Solution

     The platform is a self-service pipeline built on Cloudflare. A browser POSTs to a Worker /submit route, which validates the requested name, applies rate limiting and collision checks in D1, and inserts the submission. A cron job runs every 15 minutes, publishes verified submissions to Cloudflare DNS, writes a domains row, and flips them to live; submissions marked removed or rejected have their DNS record and directory entry deleted on the same tick. Requesters confirm ownership by emailing from the address on their portfolio, so questionable names can be pulled after the fact. Worker-managed DNS records are tagged managed-by:filipino-talent, so only records created by the system are ever updated or deleted. D1 and Cloudflare DNS are the single source of truth.

Key Features

✔ Free Subdomains: A zero-cost yourname.filipino-talent.com for people who cannot yet afford their own domain.
✔ Self-Service Submission: A form validates names, targets, and collisions before anything is published.
✔ Automated Publishing: A 15-minute Cloudflare cron creates DNS records and flips submissions to live.
✔ Safe Unpublish: Setting a submission to removed or rejected tears down the record and directory entry.
✔ Managed-Record Tagging: Only DNS records tagged by the Worker are ever modified, protecting the rest of the zone.
✔ Public Directory: A browsable, sortable list of claimed subdomains so users can discover each other's work.
✔ Step-by-Step Guides: Host-specific tutorials for GitHub Pages, Cloudflare Pages, Netlify, Vercel, and Canva.
✔ Open Source: Frontend and backend are MIT licensed, so other communities can fork and adapt them.
