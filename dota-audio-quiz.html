Dota Audio Quiz

A browser game where you guess the Dota 2 ability from its sound. The chgoices come from an audio embedding similarity index, so harder modes throw near-identical sounds.
Built from raw game files to a live leaderboard with Bash + Python extraction, Dasheng-1.2B embeddings, and a free-tier stack (GitHub, Cloudflare, Supabase).

Play the Web App

Project Overview

Introduction

     Dota Audio Quiz started with a simple question: can you recognize a spell by sound alone? You pick a name, choose a mode, hear a spell, and pick the right icon from a grid of soundalikes. Easy, Medium and Hard are 10-round runs that differ in how many choices you get and how similar the wrong ones are. Endless uses the hard rules and only ends when you quit - a miss just resets your streak. There's an Items mode too, and finished runs land on a shared leaderboard.

Challenges

⏺ Pulling Assets Out of the Game: Dota 2 keeps its audio and icons locked inside VPK packages and compiled metadata - nothing is web-ready out of the box.
⏺ Mapping Abilities to Audios: Hundreds of abilities, thousands of raw files, and names that rarely match the hero's folder. Doing it by hand doesn't scale.
⏺ Fair Wrong Answers: Random distractors feel cheap. The fun is in decoys that are plausible but still distinguishable.
⏺ Hosting for $0: It needed to stay online without a server bill or a free instance that sleeps.
⏺ Scores People Can't Fake: Browser scores are easy to edit, so every submission has to be validated server-side.

Solution

     It comes down to a three-stage pipeline: mine the local Dota 2 install for sounds and icons, embed every sound so the game can pick distractors by similarity, then ship the static game plus a tiny API on free tiers.

Step 1 - Dota 2 Asset Extraction from Local Install (Bash + Python)

⏺ Unpack the Local Install: Source2Viewer-CLI reads the VPKs straight from the local Dota 2 install, with shell scripts pulling thousands of sounds and icons in one go.
⏺ Compiled Metadata: Cast sounds live in compiled game scripts, so those get extracted too - that's how files are grouped by ability.
⏺ Python Cleanup: Python scripts walk the extracted tree, normalize paths and filenames, and sort audio into per-hero folders plus a spell icon tree.

Step 2 - Automatic Mapping and Audio Embeddings

⏺ One File to Rule Them All: mapping.tsv maps hero / ability / icon / sound and is the only file you edit to fix a clip.
⏺ Automated Auditing: Python checkers flag rows where the icon and sound names don't line up, only require manual review for the tricky ones.
⏺ Dedupe + Web-Ready Audio: Duplicate recordings collapse by content hash, then FFmpeg trims silence, normalizes to -16 LUFS and outputs small MP3s.
⏺ Audio Embeddings: Every sound gets embedded with the open-source Dasheng-1.2B encoder, composite recipes included.
⏺ Similarity Buckets: Cosine similarity sorts clips into near (closest 32), mid and far (farthest 32) buckets, same hero excluded.
⏺ Human-in-the-Loop Editor: A dev-only page serves mapping.tsv for quick previews and remaps (recipes included), with an automatic backup.

Step 3 - Free Deployment (GitHub + Cloudflare + Supabase)

⏺ GitHub: Holds the React 19 + Vite + Tailwind app, the Python tooling and the mapping. Generated assets are built during deploy, not committed.
⏺ Cloudflare Pages / Workers Assets: Serves the static build on the free tier with a custom domain - no server to manage, no cold starts.
⏺ Cloudflare Worker API: One dependency-free Worker handles POST /scores, POST /reports and GET /leaderboard. It re-sanitizes usernames and checks the score math, so fake payloads never reach the board.
⏺ Supabase Postgres: Scores and reports live in Postgres, plus a report_summary view that surfaces the most-reported clips so fixes are data-driven.

Key Features

✔ Similarity-Driven Choices: Choices come from embeddings, not random.
✔ Five Modes: Easy (4 choices), Medium (6), Hard (8), Endless and Items.
✔ Layered Playback: Web Audio schedules each recipe step and layer in the browser, so one "sound" can be a swing plus an impact plus a voice line.
✔ Live Leaderboard: Endless ranks best streaks, and scores are displayed.
✔ Crowdsourced QA: A report flag sends the clip, mode and reason (wrong sound, better variant, etc.) for review.
✔ Mobile-First: Touch-friendly grids, light/dark themes and lazy-loaded clips.
✔ Free Forever: Static game, Worker API and database all run on free tiers.
